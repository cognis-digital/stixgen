# stixgen has moved into huntkit

`stixgen` is now the **`huntkit stix`** module of the [**huntkit**](https://github.com/cognis-digital/huntkit) detection-engineering kit — 10 tools plus an ATT&CK-mapped detection-rule library and a live-refreshable blocklist, in one command.

```bash
pip install cognis-huntkit
huntkit stix --help      # the standalone `stixgen` command still works too
```

This repository is **archived (read-only)**. All development continues in [huntkit](https://github.com/cognis-digital/huntkit). Nothing was lost.
